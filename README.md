 🌍 World Food Production Analysis – Power BI Dashboard

This project focuses on analyzing global food production trends using Power BI. 
It provides interactive visual insights into crop-wise, country-wise, and year-wise food production data.




 📊 Project Overview

The World Food Production dashboard analyzes production data of major food crops across different countries and years.  
It helps understand global food supply patterns and long-term production trends.



 🎯 Objectives

- Analyze global food production over time  
- Compare production across countries  
- Study crop-wise production trends  
- Build an interactive Power BI dashboard  



 🗂 Dataset Information

- **Source:** Public global food production dataset  
- **File Type:** CSV  
- **Time Period:** 1961 onwards  
- **Key Fields:**
  - Entity (Country)
  - Year
  - Crop Production (in tonnes)



 🛠 Tools & Technologies

- Power BI  
- Microsoft Excel  
- GitHub  

--- 📈 Dashboard Features

- Year-wise production trends  
- Country-wise comparison  
- Crop-wise production analysis  
- Interactive filters and slicers
